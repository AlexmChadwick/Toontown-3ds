# Clothing Store tailor

The tailor is a `DistributedNPCTailor` NPC using the same purchase-movie wire
shape as the Gag Shop clerk.  The client accepts only movies for the local
avatar (except `CLEAR`, which releases the active session), and sends only the
whitelisted tailor fields generated by `source/net/dc_generated.h`.

## Protocol

`avatarEnter` starts a session.  The AI snapshots the avatar DNA, records the
customer id, and sends `setMovie(flag, npcId, avatarId, timestamp)`; the flag
is `START`, `START_BROWSE`, or `START_NOROOM` depending on ticket/closet state
([`DistributedNPCTailorAI.py:32-60`](../../ref/open-toontown/toontown/toon/DistributedNPCTailorAI.py)).
The field signature is `u8,u32,u32,i16`, matching
[`DistributedNPCTailor.py:91-122`](../../ref/open-toontown/toontown/toon/DistributedNPCTailor.py)
and the generated DC declaration.

The server's tailor countdown is 300 seconds
([`NPCToons.py:61-62`](../../ref/open-toontown/toontown/toon/NPCToons.py)).
On timeout it restores the customer's original DNA, emits `TIMEOUT`, then
emits `CLEAR` and clears the customer snapshot
([`DistributedNPCTailorAI.py:79-102`](../../ref/open-toontown/toontown/toon/DistributedNPCTailorAI.py)).
The client keeps a local deadline and cancels before it expires so the local
preview cannot remain active after the server has released the NPC.

`setDNA(blob, finished, which)` has signature `blob,i8,u8`
([`DistributedNPCTailorAI.py:113-123`](../../ref/open-toontown/toontown/toon/DistributedNPCTailorAI.py)).
`which` uses `SHIRT = 1` and `SHORTS = 2`
([`ClosetGlobals.py:1-2`](../../ref/open-toontown/toontown/estate/ClosetGlobals.py)).
The client uses the requested `finished = 1` Done/Cancel form and includes the
bit mask for the changed sections.  The intermediate browse form is also
available through the same outgoing whitelist.

## Validation and clothing lists

The AI rejects a DNA request from an avatar other than the current customer,
rejects an invalid ToonDNA net string, and logs suspicious requests
([`DistributedNPCTailorAI.py:113-129`](../../ref/open-toontown/toontown/toon/DistributedNPCTailorAI.py)).
For a paid purchase (`finished == 2`) it requires a clothing ticket (unless
free-clothes is enabled), applies the new DNA, and saves the old shirt and/or
bottom according to `which`; a bogus ticket restores the original DNA
([`DistributedNPCTailorAI.py:124-149`](../../ref/open-toontown/toontown/toon/DistributedNPCTailorAI.py)).
The server completes the movie only for the busy customer and treats
late/unknown customers as suspicious
([`DistributedNPCTailorAI.py:152-159`](../../ref/open-toontown/toontown/toon/DistributedNPCTailorAI.py)).

The available choices are `ToonDNA.getTops()` and `getBottoms()` for the
tailor's gender and collection
([`ToonDNA.py:1839-1882`](../../ref/open-toontown/toontown/toon/ToonDNA.py)).
The TTC tailor uses collection id `TAMMY_TAILOR = 2004`, whose shirt and
bottom style groups are the same as the Make-A-Toon collection
([`ToonDNA.py:1662-1676`](../../ref/open-toontown/toontown/toon/ToonDNA.py)).
The native client uses the generated equivalent tables in
`source/world/toon_dna_tables.h`, preserves the female torso size when moving
between skirt and shorts, and validates every outgoing 15-byte DNA net string
before sending it.

## Client behavior

The bottom-screen panel follows the shop panel lifecycle.  D-pad or touch
selection changes the gender-specific shirt or bottom style/color and updates
the local `ToonCache` look immediately.  `Done` sends the working DNA and
`Cancel` restores the original DNA locally before sending the original net
string.  Opening a tailor freezes movement and jumping until the panel closes.

The TTC tailor entry in the upstream NPC table is NPC id 2004 in interior zone
2521 ([`NPCToons.py:288-306`](../../ref/open-toontown/toontown/toon/NPCToons.py)).
